## Safety / further work
The endpoint is uncredentialed and restricts scans to a fixed allowlist; this is not a blanket security guarantee for arbitrary URL input or multi-tenant crawling. Broad-host scanning would require a separate SSRF-hardened fetch system with DNS/egress controls, rate accounting, provenance, privacy notices, and authorized usage.

After publishing, run public UI, 301→200 redirect, blocked private-target, healthy asset and existing route checks. Preserve the previous Cloudflare Worker version and ForgeHost snapshot for rollback.
